# Artwork Proof Agent

Independent portfolio demonstration by Shashank. Not affiliated with Sticker Mule.

**Development in progress. Not production ready.** Python/FastAPI performs deterministic artwork inspection, Claude orchestrates bounded visual analysis, and React/TypeScript presents versioned findings and human-approved proofs.

Demonstration print specifications only; not commercial print certification. No artwork is sent to a printer. Public release is gated on safety tests and real-provider evaluation. No open-source licence has been granted for original project code.
